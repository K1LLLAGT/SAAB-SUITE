# Building saab-workshop.exe

`saab-workshop.exe` is the Windows companion launcher for the SAAB_SUITE
workshop `vendor/` tree. It is a thin, dependency-free Python application
(`saab_workshop/`) packaged with PyInstaller.

## What this EXE does and does not do

**Does:**
- Provides a CLI and a small Tkinter GUI to organize and launch OEM
  diagnostic tools (GDS2, Tech2Win, GlobalTIS, WIS, EPC, J2534/Mongoose
  drivers) that you already have installed or downloaded yourself.
- On `extract`, copies files from a folder **you point it at** into
  `%USERPROFILE%\SaabWorkshop\vendor\<category>\`.
- Verifies file integrity via SHA256 against the JSONL manifest produced
  by `Unified_Termux_Shell_Environment_Installer.sh` on the Termux side
  (`tools/workshop/file_properties.sh`), when one is available.
- Logs everything and never crashes when a tool is missing -- `launch`
  reports a clean, logged failure instead.

**Does not:**
- Does not embed, bundle, download, or redistribute any OEM binary, ISO,
  driver, or license file inside the EXE. The `vendor/` payload is always
  supplied by the user at runtime, never compiled into the artifact.
- Does not connect to the internet.

This mirrors the policy already documented in the root `SECURITY` file and
`vendor/README.md`: third-party diagnostic software has its own license
terms and is never redistributed by this project.

## Prerequisites (Windows build host)

- Windows 10/11
- Python 3.11+ (added to PATH)
- Git (to have cloned this repository)

```powershell
cd packaging\windows
python -m venv .venv
.venv\Scripts\activate
pip install --upgrade pip pyinstaller
```

`saab_workshop` itself has no third-party runtime dependencies -- it only
uses the Python standard library (`argparse`, `hashlib`, `json`, `logging`,
`pathlib`, `shutil`, `subprocess`, `tkinter`).

## Build

```powershell
cd packaging\windows
pyinstaller saab_workshop.spec
```

Output: `packaging\windows\dist\saab-workshop.exe` (single-file,
console-enabled so CLI subcommands print output; the `gui` subcommand
still opens the Tkinter window from the same executable).

To rebuild cleanly:

```powershell
pyinstaller --clean saab_workshop.spec
```

## First run

On first run, `saab-workshop.exe` creates:

```
%USERPROFILE%\SaabWorkshop\
    config.json
    logs\
    manifests\
    vendor\
        gds2\
        tech2win\
        globaltis\
        wis\
        epc\
        j2534\
        canusb\
        tech2\
        mongoose\
        firmware\
        isos\
```

Populate it from a source you control (a synced copy of the Termux-side
`vendor/` tree, a USB drive, an already-installed vendor folder, etc.):

```powershell
saab-workshop.exe extract --source "D:\SaabWorkshopSync"
saab-workshop.exe list
saab-workshop.exe launch gds2
saab-workshop.exe gui
```

If you copy over the `manifest-*.jsonl` and `manifest-*.jsonl.sha256`
files generated by the Termux installer into
`%USERPROFILE%\SaabWorkshop\manifests\`, `extract`, `verify`, and `launch`
will all cross-check SHA256 hashes against that manifest and refuse to
trust a file whose hash does not match.

## CLI reference

| Command | Description |
|---|---|
| `extract --source PATH [--manifest PATH] [--include-unclassified]` | Sync files from `PATH` into `vendor/` |
| `verify` | Check every file under `vendor/` against the newest manifest |
| `list` | Show which registered tools are currently discoverable |
| `launch CATEGORY [--index N] [--no-verify]` | Launch a discovered executable |
| `gui` | Open the Tkinter interface |

Categories: `gds2`, `tech2win`, `globaltis`, `wis`, `epc`, `j2534_driver`,
`mongoose`, `canusb_driver`, `tech2_driver`.

## Relationship to `packaging/windows/installer.iss`

`installer.iss` builds a separate Inno Setup companion installer targeting
the Win7-SAAB/WinXP-SAAB VMs described in `packaging/windows/README.md`.
`saab-workshop.exe` is independent of that installer and can be shipped or
run standalone; you may also add the built `dist\saab-workshop.exe` to
`installer.iss`'s `[Files]` section if you want Inno Setup to place it
alongside the VM tooling.
