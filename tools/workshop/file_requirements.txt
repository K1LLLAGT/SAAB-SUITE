# =============================================================================
# file_requirements.txt
# SAAB_SUITE / Termux Workshop Environment -- system requirements manifest
#
# Consumed by Unified_Termux_Shell_Environment_Installer.sh during the
# "bootstrap" and "dependency install" phases. Each non-comment,
# non-blank line is one of:
#
#   pkg:<termux-package-name>          -> installed via `pkg install -y`
#   bin:<binary-name>                  -> must resolve via `command -v`
#                                          after pkg install; fatal if missing
#   pyreq:<pip-requirement>            -> installed via `pip install` inside
#                                          the workshop venv
#   dir:<path>                         -> must exist (created by
#                                          file_structure.sh) before scanning
#   env:<NAME>=<default-value>         -> exported by file_system.sh if unset
#   perm:<termux-api-permission>       -> requested via termux-setup-storage /
#                                          Android runtime permission dialogs
#   category:<name>                    -> a Saab diagnostic tooling category
#                                          the organizer must be able to
#                                          classify files into
#
# NO vendor OEM binaries, ISOs, installers, or license files are listed
# here or fetched by the installer. This project never bundles or
# redistributes third-party diagnostic software (GDS2, Tech2Win, GlobalTIS,
# WIS, EPC, J2534 vendor drivers). See SECURITY for the project-wide policy.
# The installer only creates the *shape* of vendor/ and organizes files the
# user already possesses on their own device into that shape.
# =============================================================================
